# 神话堡垒之地 (Mythic Bastionland) - Companion App 网页版跑团辅助工具

[![Deploy to GitHub Pages](https://github.com/jeffdyuyi/Mythic-Bastionland-sheet/actions/workflows/deploy.yml/badge.svg)](https://github.com/jeffdyuyi/Mythic-Bastionland-sheet/actions/workflows/deploy.yml)

> ⚔️ 本工具是为 tabletop RPG 游戏《神话堡垒之地》(Mythic Bastionland) 打造的免费开源线上跑团辅助面板，包含完整的 72 骑士原型图鉴、自动化角色卡、六边形地图绘制、裁判（GM）灵感生成器等功能。
>
> 🌐 **在线使用地址**：[https://jeffdyuyi.github.io/Mythic-Bastionland-sheet/](https://jeffdyuyi.github.io/Mythic-Bastionland-sheet/)

---

## 🌟 主要功能特性

- **⚔️ 骑士 (Player) 控制台**：
  - **72 骑士原型图鉴**：完整收录官方 72 种骑士原型、核心美德、战技、策略与伤疤描述。
  - **动态角色卡**：一键生成/自定义骑士角色卡，自动计算防护值（Armour）、护体（Guard）与美德（Virtue）。
  - **战斗辅助系统**：自动处理伤害判定、伤疤效果与疲劳状态追踪。

- **👑 裁判 (GM) 控制台**：
  - **六边形地图画板 (Hex Map Canvas)**：支持自定义画质、地形标记、地块探索状态记录与地图保存导出。
  - **灵感火花与战报记录 (Sparks & Myths)**：提供随机事件灵感火花与神话战报时间线编排。

- **📱 PWA 离线支持**：支持安装到桌面与移动设备主屏幕，全功能离线可用。
